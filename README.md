# Astro Session Planner

A deep-sky astrophotography night planner: pick a site, see what is worth shooting tonight, and plan the session around your horizon and the Moon. A static web app (Svelte 5 + TypeScript + Vite) with no backend, installable as a PWA (on iPhone: Safari, Share, Add to Home Screen) and usable offline after one load.

## Privacy

Your site location and horizon profile are stored only in your browser (local storage) and never leave your device. The only thing that would ever be sent anywhere is a weather lookup (a later feature), and that would send coordinates rounded to a coarse precision, nothing else.

## Development

```sh
npm ci
npx playwright install chromium   # one-time, for the e2e tests
npm run dev        # dev server
npm test           # unit tests (Vitest, tests/unit)
npm run check      # svelte-check + tsc
npm run build      # production build into dist/
npm run e2e        # builds, then Playwright smoke tests against vite preview
```

Icons are generated by `node scripts/make-icons.mjs` (Node built-ins only) and the PNGs are committed.

## Catalog

`public/catalog.json` is built from OpenNGC data with `npm run build:catalog` (`scripts/build-catalog.ts`). Rerun it to rebuild the catalog.

## Deployment

Pushing to `main` runs `.github/workflows/deploy.yml`: unit tests, type checks, e2e, then deploy to GitHub Pages.
