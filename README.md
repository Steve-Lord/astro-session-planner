# Astro Session Planner

A deep-sky astrophotography night planner. Static web app (Svelte 5 + TypeScript + Vite), no backend, installable PWA.

## Scripts

- `npm run dev` – dev server
- `npm run build` – production build
- `npm test` – unit tests (Vitest, `tests/unit`)
- `npm run e2e` – Playwright smoke tests against `vite preview`
- `npm run build:catalog` – build the catalog data file
